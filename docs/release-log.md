## v2026.08.28 — 第2号（手動配信・タイムゾーン不具合の緊急対応）

- 2026-08-28: **本日分をClaudeが手動配信**（push済み=自動デプロイ）。記事4本(すべて放射線系)。
  headline: 膝MRIのAI国際コンペ始動、MRI室の重大事故を教材に安全を再点検、FDA承認AIの「効く証拠」問題、遠隔読影の大型再編。
- 手動配信の理由=不具合: cron `0 21 * * *` UTC(=JST 6:00)は実行時点でUTC前日のため、
  素の `date`(UTC)で号の日付を決めると1日ずれ、同日重複ガードが既存号と衝突して**自動配信がスキップ**
  されていた。2026-08-28朝に全スキップが発生。
- 恒久修正(コミット 0c19501): ランブックとルーチン本体のプロンプトを、日付は必ず
  `TZ=Asia/Tokyo date` でJST基準に取得するよう修正。同日重複ガードもJSTの今日と一致するときのみスキップ、
  前日以前の号しかなければ必ず新規配信、と明確化。次回自動実行(JST 8/29 6時台)から正常化の見込み。
