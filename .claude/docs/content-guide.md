# コンテンツ様式ガイド(MedAntenna)

スキーマ・文体・用語ルールの正。コンテンツを書く前に必ず読む。

## 読者定義(すべての判断の基準)

**「技師1年目基準」** — 放射線技師を志す学生と、働きはじめて2〜3年目までの若手技師が、
辞書を引かずに読み切れて理解できること。
- 国家試験レベルの基礎用語(CT・MRI・線量など)は前提にしてよい。
- それ以上の専門用語・略語・製品名は、**その場で一言説明するか `[[glossary:slug|表示名]]` でリンクする**
  (専門用語の全数ルール)。どちらもできない用語は使わない。

## ニュース(content/trends.json)

号(issue): `version`("vYYYY.MM.DD") / `date`(「2026年8月27日」のように発行日1日のみ) /
`headline`(号の見出し) / `items[]`。`updated` はファイル先頭で更新。

記事(item)のスキーマ:
- `title`(見出し), `category`(下記5分類), `source`(出典URL) — **必須**
- `lead`(導入。1〜3文) — **必須**
- `body`(続き。背景・事実。1〜3文) — 推奨
- `briefing`(要点の箇条書き。**文字列の配列**で2〜4項目) — 推奨
- `explanation`(解説。**若手技師にとって何を意味するか** — 現場・国試/認定試験・キャリアへの含意。1〜3文) — **必須**

### category(5分類・enum。validate.py が検査)

1. **装置・技術** — CT/MRI/X線/RI/放射線治療装置の新製品・薬事承認、画像処理・AI読影支援、メーカー動向
2. **検査・臨床** — 撮像技術・プロトコル・造影剤・読影・診療ガイドライン改訂など現場の話題
3. **安全・被ばく管理** — 放射線防護、線量規制・DRL、MRI安全(吸着事故等)、医療安全、PMDA通知
4. **研究・学会** — 注目論文、JSRT/JRS/JART/RSNA等の学会、国内外の研究動向
5. **制度・キャリア** — 診療報酬、タスクシフト/シェア、国家試験・認定資格、技師の働き方、業界再編

### 選定基準

- **各号の記事の半分以上は放射線技術・放射線技師に直接関わる話題**。医療一般は半分以下。
- 採否の軸は「若手技師・学生に関係があるか」。ニッチすぎる話題は入れない。
- 1号3〜6記事。動きが少ない日は2〜3記事でよい(水増ししない)。

### 医療ガードレール(厳守)

- **診療助言をしない**: 診断・治療・検査適応の推奨を書かない。読者の実務判断を代替しない。
- **source は一次情報源のみ**: 公的機関(厚労省・PMDA・原子力規制委等)、学会、査読誌、
  メーカー公式、主要報道機関。個人ブログ・まとめサイト・匿名掲示板は不可。https:// 必須。
- **研究報道の限界を明記**: 査読前(プレプリント)・小規模・前臨床であることを本文に書く。
  相関を因果として書かない。効果の表現は元文献の主張を超えない。
- **誇張・断定の禁止**: 「がんが治る」「被ばくゼロ」等の断定禁止。
  不確かな事実は書かないか「未確認」「報道段階」と明記。
- **薬機法への配慮**: 未承認の医薬品・医療機器・適応外使用を推奨と読める書き方をしない。
  承認状況(国内未承認等)を明記する。
- **患者・当事者が特定されうる記述をしない**。インシデント報道は公表事実のみ。個人非難をしない。

## 用語辞典(content/glossary.json)

スキーマ: `slug`(英小文字とハイフン) / `term` / `reading`(ひらがな) / `category`(下記enum) /
`definition`(2〜4文。です・ます調) / `context`(現場・試験でどう出会うか。任意) / `related[]`(slug配列)

category enum: `物理・原理` / `装置` / `撮像・検査` / `安全・被ばく` / `臨床` / `制度・資格`

- slug の一覧は **glossary.json 自体が正**(このガイドに重複記載しない)。
- definition も「技師1年目基準」。数式より言葉とイメージを優先する。

## 恒常ページ(content/pages/about/*.json)

`title` / `lede` / `updated` / `blocks[]`。ブロック型は h2 / p / list / table / callout / links。
demo は使わない(validate.py がエラーにする)。h2・title にリンク記法は使えない。

## 文体

- 日本語・です・ます調。1文は短く。カタカナ語の羅列を避ける。
- 「なぜ重要か」等のラベル文言は本文に書かない(表示側が Briefing / 解説 の見出しを付ける)。
- サイトの文言に開発経緯・運用都合のメタ表現を書かない。
